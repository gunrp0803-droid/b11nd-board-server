# Rules

- `ask_permission` 도구를 사용하여 권한을 요청할 때는 `Reason` 항목을 항상 한국어(한글)로 작성해야 합니다.
- `Reason` 항목에는 사용자가 어떤 권한을 왜 부여하는지 직관적으로 이해할 수 있도록 **[요청 권한 종류]**, **[요청 대상]**, **[상세 사유]**를 명확히 포함하여 작성해야 합니다.
  * 예시: `요청 권한: 파일 읽기(read_file) | 대상: /Users/dgsw59/Downloads | 사유: 다운로드 폴더 내의 설정 템플릿 파일을 참조하여 환경 설정을 비교하기 위함`
- `ask_permission` 도구를 사용해 시스템 승인 팝업을 발생시키기 직전에, 사용자가 CLI의 영문 대화상자(Allow access, Reason 등)를 쉽게 이해할 수 있도록 채팅창에 해당 요청의 **한국어 번역 가이드(권한 종류, 대상, 사유)**를 먼저 출력해야 합니다.
  * 예시:
    "잠시 후 CLI에 아래와 같은 권한 승인 창이 팝업됩니다. 1번(Yes)을 선택해 승인해주시기 바랍니다:
     - 요청 권한: 파일 읽기
     - 대상: /Users/dgsw59/Desktop
     - 사유: 바탕화면에 있는 임시 텍스트 파일을 읽기 위함"
